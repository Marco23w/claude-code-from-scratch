# Weekly report structure (canonical since 2026-09-25)

## Question
The one question this week's report answers. Title case, one line.

## Answer
Two sentences and the one number that proves it (labelled, sourced).

## <Market> (one section per market, never merged)
Target vs actual for the market's KRs. Table. Labels on every Actual.

## Sources and limits
Four lines: where each number comes from, the window, what is missing, what is weak (small sample, short window).
