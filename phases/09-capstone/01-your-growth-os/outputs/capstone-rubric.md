# Capstone rubric (phase 09)

Marco reviews the learner's Growth OS repo after one real week of use. Pass = all "must" lines.

| Area | Must | Nice |
|---|---|---|
| CLAUDE.md | who, where numbers come from, stop-and-ask list, no secrets | imports a glossary |
| STATUS.md | 3 KRs, target vs actual, every Actual labelled and sourced, as-of dates, updated this week | review-interval respected |
| Skills (2) | both run and produce the stated output | one used by a teammate |
| Agent (1) | read-only tool list, produces Verdict + Weakest assumption | used in the weekly recap |
| Hook (1) | fires on its event, does one useful thing, never blocks | sentinel pattern |
| MCP (1) | one live number in STATUS with `mcp:` source and as-of < 7 days | read-only posture stated |
| The week | 5 working days of commits in the workspace | a decision taken on a number from the OS |
| Quiz + demo | 15-minute walkthrough with Marco, 3 questions answered without notes | |

Outcome recorded by Marco in `/corso-team`: `passed` or `redo` with one line of why.
